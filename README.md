## Công nghệ / yêu cầu đã dùng
- Semantic HTML5
- CSS Variables
- Flexbox / CSS Grid
- Responsive Design
- Animate.css
- AOS (Animate On Scroll)
- CSS `:hover` và `:focus-visible`

> Không có JavaScript nghiệp vụ riêng. JavaScript duy nhất là đoạn `AOS.init()` để khởi tạo thư viện AOS theo yêu cầu đề.
